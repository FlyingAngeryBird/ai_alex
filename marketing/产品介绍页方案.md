# Seamo AI 对外产品页方案

## 目标与定位

这是一页可放入个人网站的产品项目介绍。访客应在首屏知道 Seamo AI 是面向 macOS 的中文 AI 语音助手，并在继续浏览时看清它已经实现的交互、音乐能力和技术价值。

页面以产品体验组织内容，不采用发布会、功能清单或开发日志的叙事。对外文案准确描述当前版本，并将后续方向单独说明。

## 设计方向

- **视觉依据：**以真实客户端的粒子球、语音控制栏、对话界面和音乐界面为核心画面。首屏将现有截图中的粒子与控制栏放大编排，所有产品截图都来自当前界面。
- **颜色：**深墨色 `#080b10`、浅雾绿 `#e9eee9`、薄荷绿 `#9bd9ca`、柔金 `#e4ce91`。明暗区段交替，分别承载交互路径、产品能力和技术内容。
- **排版：**大字号短标题与克制的说明文字；等宽英文只用作流程和技术标记。避免重复的通用功能卡片。
- **阅读方式：**核心能力全部在页面中展开，不要求访客切换标签才能看到。真实界面支持点击放大，方便在手机上查看细节。

## 页面结构

1. **首屏：**产品定位、核心价值、真实粒子球和语音控制栏。
2. **一次完整的交流：**开口、看见转写、获得 AI 回应、进入音乐的交互路径。
3. **语音与 AI：**自动倾听、Space 说话、实时转写、流式文字回答、回答后的语音播报；展示实际对话界面。
4. **音乐：**语音点歌、多音源搜索、歌词、收藏、播放控制、频谱驱动的粒子视觉；展示实际音乐界面。
5. **产品细节：**人设与音色、状态可感知、收起态操作与迷你播放器。
6. **技术路径：**VAD 与预缓冲、流式 ASR、豆包大模型与语音合成、GD Studio 与 Web Audio/Three.js。
7. **持续进化：**记忆、信息获取、提醒和任务协助明确标为规划。

## 真实性边界

| 当前能力 | 代码依据 |
| --- | --- |
| 自动倾听、按住 Space 说话、实时转写 | `useAutoListen.ts`、`useRealtimeVoiceRecorder.ts`、`ConversationView.vue` |
| AI 流式文字回答、完整回答后语音播报、人设与音色设置 | `llmProvider.ts`、`useConversation.ts`、`App.vue`、`SettingsView.vue` |
| 语音点歌、多音源搜索、歌词、收藏与播放控制 | `useMusic.ts`、`MusicImmersiveView.vue`、`musicStore.ts` |
| 音频频谱驱动粒子视觉 | `ParticleSphere.vue`、`useMusic.ts` |

页面不声称具备双工实时语音、长期记忆、联网查证或任务型 Agent。当前客户端截图中仍有旧名称 `lingmo`；截图未伪造替换。对话与曲目内容为展示示例。

## 部署与验证

`marketing/seamo-ai-product.html` 为源页面；`website/index.html` 与三张 PNG 保持同步，`website/` 可以直接作为静态网站根目录。页面无外部脚本、字体或图片依赖。验证桌面与手机布局、图片加载、界面放大操作和页面无横向溢出。
