# 原生语音上下文重建与恢复

依据：最终 PRD 3.2、F03a/F04d、V09，以及连接失败最多两次自动重连的既定规则。父检查点 `3697cb2`。未变更业务 Prompt、工具合同、模型供应商、界面原型或数据库版本。

## 本次实现

- 记忆/话题更正、遗忘等上下文失效关闭旧云连接时，主进程发送明确刷新原因。持续语音仍由用户开启的情况下，客户端先停止收音、清空播放队列、释放旧麦克风和音频时钟，再用新 connectionId 重新请求主进程创建会话。
- 新请求从当前人格、删除 epoch、Topic 和有效历史重新构建注册模型边界。刷新期间不继续向旧连接发送采集帧，旧连接的文字、PCM 和迟到事件不会进入新连接。
- 用户关闭连续语音、切换临时范围、文字输入接管或卸载组件都会取消恢复意图。即使麦克风授权/采集异步返回，也释放迟到的流，不擅自恢复收音。
- 网络连接故障最多两次自动重连，采用现有 runtime 的 autoReconnectAttempts。短暂连上后又断开不重置预算；实际收到新用户轮次或用户重新开启才重置。鉴权、配额、协议/服务拒绝不重试。429 单独归类配额错误。
- 原生已生成文本现在从 playedUntilMs=0 起记录。尚未收到首个播放回执的完整文本留在历史中，但不能作为已听内容带入重建上下文；完整播放后才转为 heard。
- App 复用原有 arming/armed 状态，恢复时清空旧半句字幕，不另造界面或播音通道。

## 证据

关联 7 文件、56 项测试通过，覆盖客户端清空顺序、新 ID、旧事件丢弃、待授权期间关闭、鉴权/配额不重试、初始网络失败恢复、两次预算及短连接失败；真实 SQLite/主进程 IPC 验证旧 boundary 失效、新 boundary 不含旧事实或未播内容、旧 ID 的采集帧被拒绝。网络与设备由测试替身提供，不冒充真实服务听测。

生产构建通过；首次构建暴露新增测试的 Promise resolve 类型过窄，已按实际 mock 返回类型修正。Vite 原有 bundle 提示仍存在。

后续将主进程集成用例中的 Session 替身替换为生产 NativeRealtimeSession，仅替换 WebSocket 边界。实际截取新旧 session.create JSON：新 instructions 不含旧事实和未播回复，deletionEpoch 已更新；旧 socket 已 terminate，旧音频帧/迟到回复不能写入新连接。该集成用例通过，类型检查通过；这仍是协议模拟，未连接真实云服务。

网络/鉴权/配额/刷新失败显示可操作的中文提示，不把协议错误码作为主要产品文案。后续生产构建通过，最后客户端与实际 Session/IPC 关联 10 项通过。

## 仍未通过的门槛

本地代码已提供重建/恢复，尚不能宣称云服务实际删掉旧会话或设备无缝恢复已经验收。需要用户在设置中配置已开通的原生 3.0 资源后进行真实 20 轮、有效插话、删除并发、设备拔插、网络恢复和首响/停声听测。工具更正的本地文本回执、云回复/实际播音一致性也需真实验证。G0/G2 不打通过标签，不发布安装包。
