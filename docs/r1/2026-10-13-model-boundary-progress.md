# R1 模型请求边界开发记录（G0/G2/G3 未通过）

changeId：DEC-R1-BOUNDARY-004。依据：最终 PRD v1.0 的受控执行、F02a、F04d、F08b，以及资产架构合同中的 PromptBoundary/ToolExposure。

## 变更

- PR01–PR10 按注册表编译，动态变量用对应 JSON Schema 校验；模板只替换一次，用户 JSON 中的占位符不展开。Skill 正文与声明资源按 manifest 内容哈希读取。
- 普通文字与流式聊天在实际网络请求前重建唯一 system，其他组件传入的 system 不成为业务指令；记录可核查的 Prompt hash/资产发布标识，保持用户/助手消息角色。已有 Ark Chat Completions 仅是当前开发回退通道，不能当作 PRD 要求的原生实时/Ark Responses 适配已完成。
- 工具定义从同一目录取原描述和 Schema，按频道、已加载 Skill、公共允许工具及有效授权取交集；未知别名拒绝，临时模式排除长期记忆工具。当前回退通道没有真实工具循环，授权集合为空；若误传非空工具集合，明确失败，不把工具建议当执行成功。
- 去掉由书名号歌名或旧 `play_music` 回复标签触发播放的路径。点歌必须由真实受控工具执行；因此当前语音点歌闭环仍缺失，音乐页真实搜索/播放器保留。
- 开场规则移回注册 PR03，应用只传开始会话事件数据，内部事件不落成普通用户历史。PR03 版本 1.0.1；manifest、运行配置、Prompt/Skill 注册表的发布标识统一为 2.0.1，工具 Schema 仍为 2.0.0。
- 记忆更正也推进失效 epoch；更正或忘记后，运行中的文字请求每段及提交前重新核对 epoch/人格版本，不发布或保存旧回答。主进程发出失效事件，渲染层已接停止旧播音入口；实际 TTS/原生实时会话的停止与重建仍需实测。
- Ajv 8.20.0 已作为精确版本的运行依赖；打包脚本复制其完整依赖并检查解析位置，可把检查包输出到独立目录，避免覆盖正在运行的包。
