## 本批功能与产品调整

| 用户问题 | 处理 | 范围与理由 |
| --- | --- | --- |
| 记忆更正或忘记时后台刷新 | 编辑/确认打开时冻结对象和版本；变更后返回版本冲突并保留草稿；来源缓存随刷新清空 | 防止把旧内容误写到新版本，或对用户尚未确认的新内容执行忘记 |
| 事项过期提醒被放在“之后” | 将“已过期”“今天”“之后”“未定时间”“已完成”分开；优先展示最近待触发提醒，跨午夜自动更新 | 分组按当前时间与提醒状态如实展示 |
| 长文字输入与重复提交 | 输入框支持多段，Enter 发送、Shift+Enter 换行；等待接收回执期间只提交一次；输入框长高时上移对话区 | 支持材料讨论，保留原型默认的一行紧凑外观 |
| 导航与编辑状态 | 委托切换前保留工作稿；设置称呼/音色/服务配置未保存时阻止切页并提供明确放弃入口；弹窗保持键盘焦点，关闭/保存忙时禁用误操作 | 减少误切换、焦点落到背景、草稿消失 |
| 提醒操作名称 | 已有提醒明确显示“提醒改期/保存时间”，新提醒显示“创建提醒”；无效时间和夏令时不存在时间拒绝 | 后端改期仅改变时间，不暗示正文可编辑 |
| 独立系统与数据弹窗 | 数据恢复/清理预览活动时阻止设置页切走；专注时长用整数1–180分钟校验 | 保留用户确认与预览状态 |

没有更换深色粒子视觉、侧栏与音乐沉浸结构。此次布局调整聚焦遮挡、状态归类、操作名和键盘路径。视觉一致性的历史宽/窄窗截图见 `2026-10-18-alpha20-prototype-alignment.md`；本批新增的多行输入及弹窗布局还需验收包截图。
