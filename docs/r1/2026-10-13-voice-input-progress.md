# R1 语音输入交互纠正记录（G2 未通过）

changeId：DEC-R1-INPUT-005。依据：最终 PRD v1.0 第 3.1 节 F01a/F01b/F01d。原型鼠标点击切换与最终 PRD 的按住/松开行为冲突，以最终 PRD 为准。

- 共用输入按钮改为按住开始、松开发送；鼠标捕获保证移出按钮后松开仍结束，取消/失焦/页面隐藏结束本次采集且不发送。键盘 Space 与按钮输入有各自所有权，互相松开不能提交对方录音；输入框 Space 保持空格。
- 按键录音达到 60 秒结束。快速松开会等启动结束后只提交一次；启动中取消会等实际资源到达后释放。模式切换先等手动采集清理，再启用自动会话。
- 自动会话关闭后迟到的麦克风授权结果不会重新开启采集；取消实时识别后迟到字幕不会重新出现。录音器有独立取消接口，丢弃本地音频、释放拥有的麦克风流并清理远端 ASR 会话。

证据：构建通过；46 测试文件、257 项通过。新增控制器与录音器测试覆盖所有权、快速松开、启动中取消/失败、60 秒、模式切换等待、权限迟到和字幕迟到。旧源码片段断言仅用于接线检查，不充当行为证明。

真实 Chromium 检查使用 `tests/fixtures/composer-harness.html`，仅挂载正式 Composer 并统计事件，不调用麦克风、不读写用户资料。按下计数 start=1/end=0；移出后松开 start=1/end=1；另一轮按住后将另一页置前再返回得到 start=1/end=0/cancel=1，后续松开未发送。输入框得到“今天 想聊聊”，没有新增语音事件。该 fixture 不进入正式 renderer 构建。

尚缺：真实 Mac 麦克风权限、设备拔插、语音服务、完整桌面失焦/切页/播音打断及自动与手动切换实测。当前语音仍为旧 ASR 回退路径，原生实时协议、播放仲裁和性能验收未完成，F01 与 G2 不标为通过。

回退：本切片仅在独立 R1 分支；不迁移数据库，不更改 Prompt/Skill 资产，不建立阶段通过标签。
