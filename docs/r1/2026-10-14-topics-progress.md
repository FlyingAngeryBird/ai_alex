# R1 持续话题开发与验证记录

变更 ID：DEC-R1-TOPICS-020。依据：最终 PRD 3.2、F04c/F04d、V08/V09，以及现有原型记忆侧栏「持续话题」。旧目录、分支及数据未修改。

## 已实现的链路

- 授权后的普通会话达到本地上下文窗口容量条件时，异步调用注册 PR01 + PR06、无工具火山 M03。没有自动记忆授权时不提取；开启前的历史不回填，临时会话不写长期话题。
- Topic 保存实际题目、阶段结论、未解问题、状态、来源、版本；同话题更新使用实际 ID 和 expectedVersion。程序核验来源正文、角色、状态、授权、会话、删除 epoch、人格和配置，拒绝伪造引用及未播完助手内容。新输入使旧摘要失效，并合并排队到最新来源。
- 无效结构只允许注册 PR10 修复一次。仍无效不提交；没有新增路由或评判模型。事件日志仅记录版本、来源数量等元数据。
- 生产侧栏可搜索、分页、展开话题，查看版本、实际来源及关联会话/产物，编辑结论、忘记或接着聊。接续请求传入选中的真实话题及版本；后续回答使用新结论。编辑与忘记使旧请求/提取/任务上下文失效。
- 版本历史用于用户查看，不作为旧结论重新注入模型。忘记不删除原始历史、便签、提醒；旧备份恢复时保留当前删除抑制及更正保护。
