# G2 连续交流与记忆开发记录（未通过阶段门槛）

## 已实现

- 普通会话消息落入 SQLite，记录 `sessionId`、`turnId`、`responseId`、角色和状态。临时会话消息只保存在主进程内存；退出时销毁，不进入 `sessions`/`messages` 表。
- 页面可切换临时对话。切换时清空当前对话上下文；旧异步回复在会话代数变化后不再写入新会话。临时模式中创建事项或提醒前，界面要求明确确认它们会独立保留。
- 手动记忆服务只接受已持久化的普通用户消息作为来源；临时消息不能直接成为记忆来源。召回会排除已过期、删除及来源被抑制的条目；遗忘更新删除代数和引用话题。
- 当前文字回退请求已接发布资产编译与最终 system 重建；旧语音协议仍未迁移为 PRD 要求的原生实时会话。音乐行动不再由书名号或旧回复标签触发，真实工具点歌路径尚未接通。
- 手动记忆增改忘、来源和历史搜索已接原型侧栏。更正/忘记后每个旧文本片段及最终回复核对 epoch；前端已接失效事件停止旧播音入口，真实音频停止仍待验证。

## 证据

- `tests/r1Conversations.test.ts`、`tests/r1Memory.test.ts`、`tests/chatIpc.test.ts` 覆盖内存隔离、普通持久化、来源校验、遗忘传播及旧回复丢弃。
- 打包应用界面实测临时模式进入、范围确认和退出。真实 R1 数据库中 `temporary=1` 会话记录为 0，临时提示文本未进入消息表。

- 连续实时交流、原生打断和单一播音仲裁未按最终 PRD 完整验证。
