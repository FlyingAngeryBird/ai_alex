1. 查询与生活工具：真实候选选择/比较、事项修改/完成/撤销已补，接完删除/导出可信UI动作和自然语音串联；不为同一个小改动重复打包。
2. 工作稿、记忆与跨会话：完整续改/撤销/保存/导出、临时和删除传播，补实际播报关联审计。
