## 本轮确认并修复的缺口
1. **memory_recall category 序列化 null**：真实模型输出 `"category":"null"`（字符串）被严格 Schema 拒绝，导致 F04c 失败。资产 3.5.8 允许兼容字符串 `"null"`，运行时归一为未限定分类；新增回归。
2. **memory_remember/update validUntil 序列化 null**：真实模型输出 `"validUntil":"null"` 被当作过期时间，敏感确认无法进入 pending。运行时统一归一为 null；新增回归。
3. **ARK incomplete reason=length 分类错误**：真实 F09a 请求返回 `status=incomplete, reason=length`，被笼统标为 `ARK_RESPONSE_NOT_COMPLETED`；现映射为 `ARK_OUTPUT_BUDGET_EXHAUSTED`，不发布部分结果；新增测试。
- 边界未扩大工具权限；未提高实时搜索/任务预算；未伪造成功。资产 release 3.5.8（工具 schema 仍 3.2.1）。
