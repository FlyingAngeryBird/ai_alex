# R1 设备、安静模式与实际播音状态

变更：DEC-R1-DEVICE-POLICY-024。依据：最终 PRD F01a/F01d、F07c、F08f、F10c、F11c 及 P05 设置侧栏。父检查点 `6b7aa5f`。只在独立 R1 工作树开发；旧版目录和数据未写入。本批不更改注册模型资产（仍为 2.5.1），没有新增业务 Prompt 或模型工具。

## 已实现的完整路径

- 设置侧栏增加折叠的「设备与安静模式」：输入/输出设备、勿扰、主动语音；真实 SQLite 保存与类型化 IPC，使用版本检查并广播提交后的状态。不会通过原型 localStorage 保存正式数据。
- SQLite 8→9 自动保留升级前快照；原有音乐队列及音量保留。设备 ID 只用于本机选择，不输出到诊断日志。数据回退须完全退出应用，用隔离副本和升级前数据库，不能用旧代码直接打开 schema9。
- 所选输入接入原生会话、实时 ASR、键盘录音及自动会话。切换输入停止当前收音；设备拔出、取消、迟到授权和迟到服务启动清理实际资源。正常待机与只读刷新列表不申请麦克风。
- 输出接入原生 PCM、回退 TTS、音乐元素及音乐分析上下文。切换按顺序执行，迟到旧结果不覆盖新选择；失败、拔出或超时停止播音并显示可恢复提示，不偷偷改用另一设备。超时对象不复用。
- 勿扰/关闭主动语音阻止自动问候的实际发声，已在途的主动播音也停止；用户发起的回复与音色试听可用。提醒保留真实投递状态，勿扰时请求静默系统通知，不声称系统已展示或用户已读。不修改 macOS 专注设置。
- 助手说话状态以音频 `playing` 事件为准；移除伪造的正弦振幅。用户输入活动来自实际采样/VAD，音乐降音跟随输入和真实播音活动，结束后恢复当时基准音量。
- 实际 Cmd+Q 检查发现并修复退出顺序缺陷：最终退出销毁窗口时不再读取已关闭 SQLite，也不再因 activate 创建新窗口。关闭窗口保留后台和彻底退出仍遵循原有 macOS 规则。
