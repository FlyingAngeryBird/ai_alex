# 工作稿局部续改与原始材料

变更 ID：DEC-R1-ARTIFACT-EDIT-021。依据：最终 PRD 3.6、F09b/F09c、V22，现有原型的「查看原始想法」、讨论稿及续改提示。父检查点 `91ce1bd`。只修改独立 R1 工作树，旧目录、旧数据未改动。

## 已实现的完整代码路径

1. 当前可见/聚焦稿件通过真实 IPC 选中实际 artifactId/version。正文选区从浏览器 UTF-16 转为 Unicode 码点；模型的段落序号由程序按空行计算范围，不让模型手算偏移。隐藏的其他编辑器不自动抢选中对象。
2. 普通文字与原生会话共享当前稿及版本。主会话只提出 artifactTarget；程序核验它确实来自当前稿，拒绝未知 ID、旧版本和扩大用户选区。更改上下文会停止旧请求；记忆失效清除旧稿的自动上下文引用，独立稿件本身保留。
3. Task 保存受控的完整基准、范围和实际来源，TaskInput.currentArtifact 直接提供完整原稿；同一资料也有当前任务独占的只读 current-artifact.json。普通任务持久保存，临时资料/任务/稿件只存内存。
4. Supervisor 要求续改发布同一 Artifact 的新版本；完整成功不能没有稿件，不能另建副本代替。范围外正文和标题必须保留，提交前再次核对基准版本。新增真实来源，原始来源仍可追溯。范围不合法最多一次无工具 PR10 修复，仍无效不发布。
5. 编辑器订阅实际版本事件，干净状态读取新稿；有本地修改时保留文字并展示当前版本，用户核对后选择采用新版或更新它，后者仍带 CAS 版本检查。撤销上次模型修改创建新版本；保存为记录继续沿用同一事项。
6. 原始想法按钮读取真实来源正文，临时范围不能读取普通稿；没有材料时明确说明，不填演示原文。超限按统一配置提示并保留文字，不使用 HTML maxlength 静默截断标题。
7. 文字提交前等待当前稿的本地保留，避免把尚未保存的旧版本交给模型。冲突或超限时保留编辑器文字、暂不把该稿作为有效上下文，仍可继续普通聊天，不等待后台模型完成。
