# R1 历史侧栏开发记录（未通过 G2/G5）

changeId：DEC-R1-HISTORY-003。依据：最终 PRD v1.0 的 P01 辅助层、F04e、F11a，以及 R1 原型历史侧栏。

问题：旧入口只显示当前渲染层的消息，关闭应用后无法从入口查看已经持久化的会话。

本次变化：侧栏从 R1 SQLite 读取普通会话，按最近消息时间排列，每页 20 个会话；正文搜索在主进程执行，展开会话显示真实角色、原文和时间。空会话、临时会话、手动记忆来源会话不进入历史。临时模式下主进程拒绝列表与正文读取，渲染层同步清空已加载内容并丢弃旧异步响应。没有新增数据库表或修改 Prompt/Skill 资产。

验证：`npm run build` 通过；`npm test -- --run`：43 文件、240 项通过。新增用例覆盖超过 20 个会话的无重复分页、正文检索、字面 `%`/`_` 查询、来源隔离、非法页码和临时模式 IPC 拒绝。本机开发包已目视检查侧栏空状态；切换临时模式后显示禁止读取，再切回普通模式恢复入口。没有写入演示历史。当前包只有本机开发签名，未公证或安装验收。

尚缺：基于 Topic 的历史分组、历史续聊的安全上下文恢复、历史删除范围和有数据时的实际界面验证。没有真实模型配置，当前用户目录中没有可展开的真实会话；单元测试不等同于该项实包验收。G2/G5 保持未通过。

回退：切片保存在独立 `codex/seamo-r1`，回退源码不修改 R1 数据和旧版目录；本次未建立阶段通过标签。
