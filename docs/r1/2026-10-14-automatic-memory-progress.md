# R1 自动记忆开发与验证记录

变更 ID：DEC-R1-AUTO-MEMORY-019。范围：最终 PRD 3.2 / F04b、V08，现有原型「记住重要的事」开关与 confirmMemory 弹窗。工作目录 ai_alex-r1，分支 codex/seamo-r1；旧目录、分支与数据未改动。

## 本轮实现

- SQLite 持久保存自动记忆授权，默认关闭。设置开关读写真实主进程状态，并校验授权版本；开启仅处理后续完成的普通轮次，不回溯旧历史。关闭立即取消当前提取及队列，并撤销自动敏感候选；已保存的记忆保留。
- 普通文字完成轮次异步调用火山 Ark，无工具 M03，最终请求只来自注册 PR01 + PR05，使用原 MemoryInput / MemoryCandidates Schema，store=false。提取不阻塞主会话，也不增加额外语义路由或评判模型。
- 提交前再次核验用户授权版本、真实消息 ID/turnId/正文/状态、会话范围、删除 epoch、人格及服务配置版本。拒绝伪造引用、未知替代目标、额外字段、迟到结果与部分无效提案；整批预校验后再事务提交。时间锚点采用实际用户轮次发生时间。
- Memory 记录 explicit/automatic 授权及自动授权版本，保留来源。相同内容合并，明确更正建立新版本并使上下文失效；显式确认过的相同记忆不因新增自动来源降为自动授权。
- PR05 输出敏感来源 ID 时，原文候选只留内存。现有 Schema 的敏感判断是来源轮次级：混合轮次整体不自动写入，先让用户选择原话中的一件事，再展示固定内容及范围供第二次确认。拒绝跨窗口、伪造内容、取消、旧授权与旧轮次；取消不写入。
- 补充敏感写入保护覆盖常见健康症状表述，拦住模型漏标的偏头痛案例。这个检查只是保守提交保护，不能声称覆盖所有敏感语义。
- 使用指定原型的 switch 样式与现有确认弹窗布局。界面显示默认/开启、处理中、失败、冲突，保存后刷新真实记忆。关于我页可管理四类语义记忆及授权来源，持续话题仍需独立 Topic 实现。
- 原生语音在完成响应或实际播放完成后接提取；只接受 question_id 能绑定实际用户来源、且响应记录对应同轮的情况。没有来源绑定时不猜测提取；该入口尚未用真实 3.0 配置/设备验收。
