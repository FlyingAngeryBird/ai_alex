# R1 记忆候选确认开发记录

变更 ID：DEC-R1-MEMORY-CONFIRM-018。范围：F04a/F04b 的敏感候选确认、F04e 临时对话显式保存；参照最终 PRD 3.2 和原型 confirmMemory 弹窗。原目录和旧分支未修改。

## 已接通

- 普通敏感记忆的记住/更正先产生内存候选及 `confirm_memory / awaiting_user`，没有提交成功回执。用户看到具体内容、归类、影响范围和有效期后，由界面提交不透明令牌。
- 临时主会话仅开放 `memory_remember` 的保存候选入口；仍不开放召回、更正、遗忘或 Task 记忆访问。确认成功后只为展示内容建立用户确认来源，创建普通会话，再销毁临时消息及未提交 Task。其余临时聊天不进入数据库。
- 取消不保存、不退出临时模式；同一已取消用户轮次不能自动重提。新用户轮次撤销旧候选。确认绑定窗口、真实来源、当前上下文和对象版本；伪造内容/授权标志、跨窗口、过期、旧来源和版本冲突被拒绝。
- 提交重放返回同一实际结果。重放缓存只保留已提交 DTO，丢弃原临时正文及上下文闭包。窗口全部关闭时撤销未提交候选；没有后台自动保存。
- 使用现有原型确认布局、文字和现有弹窗样式；补上键盘焦点约束、取消后焦点恢复、保存中状态和错误提示。保存成功刷新记忆侧栏，临时退出同步重置会话和 Task 范围。
- 用户作出选择时停止“待确认”的旧播报，不撤销确认权限。文字回退的异步 TTS 增加播放轮次检查，停止后迟到的合成音频及旧播放回调不能抢回播放权；这一保护仍需要真实设备音频验收，不以弹窗测试代替。

## 资产与兼容性

releaseId 与 schemaVersion 升至 2.2.0，PR03 升至 1.1.0。修改同一资产源：记忆工具描述、临时频道曝光规则和 ToolOutput 的等待动作；重建生成文档及 manifest。既有成功回执字段、38 个业务工具、3 个内部工具、6 个 Skill、10 个 Prompt 保持。`export` 等待结果仍有效。

待确认记忆是界面等待结果，不是已提交 Memory、后台 Task 或成功 Receipt。运行时只允许记忆保存/更正工具使用该确认动作。临时 Task 的记忆工具继续隐藏；普通 Task 保持已绑定资产发布，不自动迁移。

回退源码时连同资产整体回退，使用隔离测试数据目录；不得让旧代码覆盖当前删除抑制。候选不持久化，重启后不自动恢复或提交。

## 验证证据

- 静态资产及合同样例检查通过；来源/授权/版本的判断由程序集成检查验证。
- 关联检查 41 项通过：记忆服务、记忆会话、候选服务及 IPC、真实 chat 临时退出桥接、PromptBoundary/ToolExposure、旧请求失效及预加载 API。新增候选预校验另行验证空内容和非法日期，不能先弹出无效候选再写入失败；新增退出通知失败检查，确认实际模式仍切换、临时正文仍销毁、原生会话关闭回调仍执行，下一轮写入新普通会话。候选专项最终 9 项通过。
- 真实 Ark 使用合成输入与独立内存库：敏感取消案例 3643ms，候选“我对花生过敏”，确认前后有效记忆均为 0；临时确认案例 4032ms，候选“用户喜欢无糖茶”，确认前无写入，确认后 1 条记忆、退出临时模式，额外临时正文没有进入数据库。该脚本以程序模拟用户选择，不冒充人工界面验证，也不发送用户真实历史或打印凭据。
- Electron 真实界面/IPC，独立临时数据库，1000×760 窗口：普通敏感弹窗展示内容及敏感范围；点击“不保存”后实际记忆 0 条。临时弹窗说明退出及其余内容清除；点击“继续临时对话”后仍为临时模式，普通记忆读取返回隔离错误。再次提出请求并确认后，界面显示普通模式、实际记忆 1 条、实际来源“喜欢无糖茶”。Tab 焦点进入弹窗按钮，取消后回到触发按钮。使用组件是生产确认组件，fixture 仅提供合成模型输入和检查入口。
- 生产构建通过。没有声称完整应用原型同尺寸验收、设备连续语音或正式安装验证通过。

检查入口：`scripts/check-memory-confirmation.mjs`（可选单案例）；`tests/fixtures/memory-confirmation-runtime.mjs` / `.html`（独立真实 IPC 界面）；`tests/memoryConfirmations.test.ts`。
